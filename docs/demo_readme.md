# SCADA Predictive Maintenance · Demo для KEGOC

Историческая демонстрация оценки риска отказа в следующие 7 суток по данным CARE v6 Wind Farm A. ZIP содержит реальные SCADA-показания, обе обученные модели с предобработкой, прогнозы validation и test, пороги, метрики и TreeSHAP.

## Запуск на Windows

1. Распакуйте ZIP в отдельную папку. Откройте PowerShell в каталоге с `app.py`.
2. Проверьте версию `py -3.14 --version`. Сборка проверена с **Python 3.14.6 x64**. Если команда `py` недоступна, проверьте `python --version` и используйте `python -m venv .venv`.
3. Создайте окружение и запустите Dashboard.

   ```powershell
   py -3.14 -m venv .venv
   $python = '.\.venv\Scripts\python.exe'
   & $python -m pip install -r requirements-dashboard.txt -c requirements-windows-lock.txt
   & $python -m pip check
   & $python -m streamlit run app.py
   ```

4. Откройте [http://localhost:8501](http://localhost:8501). Для занятого порта добавьте `--server.port 8502`. Для остановки нажмите **Ctrl+C**. Прямой вызов интерпретатора окружения работает без активации PowerShell.

Интернет нужен при установке пакетов из PyPI или корпоративного зеркала. После установки Dashboard использует файлы из распакованной папки. Эталонные версии указаны в `requirements-windows-lock.txt`. Используйте `joblib` только из доверенного ZIP и сверяйте его SHA-256.

## Быстрая демонстрация

1. **Overview** → турбина 21 → событие 22. Видны H7, результаты теста и настоящие предупреждения.
2. **SCADA Monitoring** → выберите два датчика, например температуру воздуха и скорость ветра.
3. **Failure Prediction** → сравните score и пороги. Включите **Воспроизведение**, чтобы перемещать исторический срез времени.
4. **Model Explainability** → gain, Global TreeSHAP и важность датчиков. В **Локальном SHAP** выберите момент. Появится объяснение LightGBM и подтверждение, что обе модели воспроизвели архивные score. В **Истории датчика** видны физические показания.

Автоматическая проверка из каталога Demo — `& $python -m scripts.verify_distribution`. Она загружает все прогнозы, обе модели, SCADA и проверяет четыре раздела.

## Границы демонстрации

Тест охватывает два отказа одной турбины. Logistic Regression обнаружила один отказ. LightGBM при фиксированном пороге не обнаружил ни одного. Score некалиброваны. SHAP объясняет оценки LightGBM. Установление физической причины требует отдельных данных.

Демо содержит десять каналов из наблюдаемых разделов `prediction` и точные строки признаков для 1 473 сохранённых моментов validation и test. Для повторения предобработки и обучения нужен Full. [Атрибуция и лицензия данных](DATA_LICENSES.md)
